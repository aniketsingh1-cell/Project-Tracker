# Project Report Tracker

Ab app Google Sheet se data load karta hai aur preview table me dikhata hai.

## Use
1. `index.html` browser me open karo.
2. Sheet URL aur `gid` do.
3. **Load Sheet Data** click karo.

Default me yeh sheet pre-filled hai:
